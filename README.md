# Python Playlist System

Console-based music playlist manager written in Python 3 using vscode.

## How to run
1. Download the files into one folder.
2. In a terminal inside that folder, run: python ENTERPRISE_SOFTWARE_ENG_ASSIGNMENT2.py
3. Login: username user123, password Givemetheykey123
4. Choose option 1 and type playlists.txt to load the sample playlists.

## How to run the tests
python test_playlist.py

## Notes
- Playing music (option 14) works on Windows only.
- Uses only Python's standard library, so nothing needs installing.
- To play music, run: python -m pip install pygame
